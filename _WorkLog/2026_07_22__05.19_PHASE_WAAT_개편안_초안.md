# WAAT 개편안 초안 작업 로그

## 목표

기존 `개선방안` 대화의 방향과 현재 WAAT 소스코드를 바탕으로, AI 수다방과 WAAT를 연결하는 웹사이트 개편안 초안을 작성한다.

## 단계

- [x] Phase 1. 기존 아이디어와 현재 기능을 대조해 개편의 전제와 문제 정의를 정리한다.
- [x] Phase 2. 정보 구조, 핵심 사용자 흐름, 화면별 역할, 운영 원칙을 설계한다.
- [x] Phase 3. 우선순위, 단계별 실행 범위, 성공 지표를 포함한 초안을 작성하고 원문과 대조한다.

## 범위

- 기획 문서 작성만 수행한다.
- 기존 소스코드와 운영 데이터는 변경하지 않는다.
