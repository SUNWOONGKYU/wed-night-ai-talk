# WAAT 게시판 아젠다 상단 고정

## 목표
- 관리자가 현재 논의할 아젠다 게시글을 최대 3개까지 상단에 고정할 수 있게 한다.
- 고정글은 일반 게시글보다 먼저 표시하고, 일반 회원은 고정 상태를 변경할 수 없게 한다.

## Phase
- [x] 1. 기존 게시글 스키마, 관리자 화면, 목록 로직 확인
- [x] 2. 고정 상태, 최대 3개 제한, 관리자 제어와 목록 표시 구현
- [x] 3. SQL 제약과 실제 브라우저 흐름 검증

## 결정
- 고정글은 최신 고정 순서로 표시한다.
- 최대 3개를 넘기는 고정 요청은 서버 측에서 거부한다.

## 검증
- 운영 Supabase에 마이그레이션 적용 및 적용 이력 확인.
- 운영 도메인 비로그인 브라우저에서 게시글 40개 정상 로드, 신규 자산 로드, 고정 제어 버튼 비노출 확인.
- 비로그인 RPC 요청은 HTTP 401로 차단됨.
