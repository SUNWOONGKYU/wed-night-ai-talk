# 보물창고 자료 게시글 대조 및 게시

## 목표
- 공지의 보물창고 16개 자료를 WAAT 게시판과 대조한다.
- 이미 게시된 자료는 제외하고, 누락 자료만 자료별 게시글로 준비한다.
- 게시 전 PO에게 누락 목록과 게시 문안을 제시하고 최종 승인을 받는다.

## Phase
- [x] 1. 보물창고 16개 기준 목록과 현재 게시판 게시글 수집
- [x] 2. 제목·본문·원문 링크를 기준으로 중복 여부 판정 및 게시 문안 작성
- [x] 3. PO 최종 승인 후 누락 자료 게시 및 게시 결과 검증

## 기본 분류
- 누락 자료 게시글의 기본 카테고리는 `공부하기`로 한다.

## 대조 결과
- 기존 게시: Claude 3계층 작업팀, 에신, 웹세션 자동화, 옵신, Pocket Command System, SUNNY AI MAGIC 50, AI 에이전트 이해 및 제작 방법.
- 게시 대상: MBO 천상, YouTube Generate, 스킬 제조 공장, 검토·평가 코어, Claude Code 원격 제어 방법 18가지, AI끼리 서로 일을 주고받게 하는 방법, AI와의 서술형 스무고개 문답법, 컴퓨터 유즈·브라우저 유즈·Claude in Chrome, AX 실전 4법 체계.
