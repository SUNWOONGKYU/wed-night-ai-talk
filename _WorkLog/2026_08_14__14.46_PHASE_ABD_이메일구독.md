## 고정 계약

- 구독 폼은 ABD 전용 화면 제목·캐치프레이즈 바로 아래에만 표시한다.
- 회원은 검증된 Supabase Auth 이메일을 사용하고 비회원은 이메일을 입력한다.
- 이메일은 정규화·중복 방지하며 원문을 로그·스크린샷·일반 API 응답에 노출하지 않는다.
- 구독 테이블 직접 쓰기는 차단하고 검증 RPC만 `anon`, `authenticated`에 허용한다.
- 목록은 기존 `public.is_admin()` RLS를 통과한 관리자만 조회한다.
