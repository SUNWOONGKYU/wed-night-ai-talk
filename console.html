원맥스 / One MACS · PC 준비

폰 앱에서 오셨나요? 여기서 3단계만 하면 폰에 넣을 코드 8자리가 나옵니다.

PC 쪽은 Claude Code가
대신 설치합니다.

사람이 할 일은 Node.js 설치 → Claude Code 설치·로그인 → Claude Code에게 설치 지시입니다. 지시하면 Claude Code가 필요한 것(어떤 AI를 함께 쓸지, 모델, 프로젝트)을 물어보면서 설치를 진행합니다.

지금 폰으로 보고 계시네요. 아래 단계는 Windows PC에서 해야 합니다. PC 브라우저에서 waat.community/console 을 열면 각 단계에 [복사] 버튼이 나옵니다.
이미 Claude Code가 있으면

⑤ C:\원맥스 폴더에서 claude 실행 → ⑥ 설치 지시문 붙여넣기 → Claude Code의 질문에 답하기.

1

Node.js LTS 설치

https://nodejs.org 에서 LTS 버전을 받아 설치합니다. 설치 화면은 전부 "Next"로 넘기면 됩니다.

설치가 끝나면 PC를 한 번 재부팅하세요. (재부팅 안 하면 다음 단계에서 npm을 못 찾는 경우가 많습니다)

2

터미널 열기

Windows 시작 버튼 → "터미널" 입력 → 실행 (없으면 "PowerShell").

검은(또는 파란) 실행 창에 커서가 깜빡이면 준비된 것입니다.

이 실행 창은 설치가 끝날 때까지 닫지 마세요.

3

Claude Code 설치

아래 명령을 복사해 터미널에 붙여넣고 Enter.

npm install -g @anthropic-ai/claude-code

1~2분 걸립니다. 'added … packages' 가 나오면 성공.

4

로그인

터미널에 claude 를 입력하고 Enter → 브라우저가 열리면 Anthropic 계정(Claude Pro/Max 구독)으로 로그인 → 터미널로 돌아옵니다.

claude

Claude Code는 Claude 구독이 있어야 씁니다. 구독이 없으면 claude.ai 에서 Pro 이상을 먼저 결제하세요. 로그인이 끝났으면 /exit 로 일단 나옵니다.

5

C:\원맥스 폴더를 만들고 그 안에서 Claude Code 실행

원맥스가 설치될 폴더입니다. PowerShell(또는 터미널)에 아래를 붙여넣으면 폴더가 만들어지고 그 안에서 Claude Code가 켜집니다.

mkdir C:\원맥스; cd C:\원맥스; claude

다른 폴더를 쓰고 싶으면 cd 그폴더; claude. 설치가 끝나면 이 폴더 안에 _mobile_remote(콘솔)와 "트레이딩 시그널"(기본 프로젝트) 폴더가 생깁니다.

6

Claude Code에게 설치를 지시하기

Claude Code 입력창에 아래 지시문을 붙여넣고 Enter. 이후 Claude Code가 물어보는 것에 답하면 됩니다.

https://www.waat.community/console/install.md 를 읽고, 그 안의 지시를 순서대로 전부 수행해서 원맥스를 설치·실행해줘.

이후는 Claude Code가 알아서 합니다: 파일 다운로드 · 설치 · 설정 · 실행 · 페어링 코드 발급. 중간에 로그인이나 확인을 물으면 답해 주세요. 끝나면 페어링 코드 8자리를 알려줍니다.

Claude Code가 URL을 못 읽는다고 하면 consolesystem_v2.zip(18MB)을 받아 작업 폴더에 풀고, "CLAUDE_CODE_설치지시문.md 파일을 읽고 그대로 수행해줘"라고 하세요. 지시문 원문: install.md

7

폰: 앱 열고 페어링 코드 입력 → 끝

앱(/market/onemacs)을 설치한 폰에서 원맥스를 열고, PC가 알려준 페어링 코드 8자리를 입력하면 연결됩니다. 이후 PC가 켜져 있으면 어디서든 핸드폰에서 작업을 시킬 수 있습니다.

트레이딩 봇 · 원맥스에 포함

트레이딩 봇 설치 (선택)

원맥스의 "트레이딩 시그널" 프로젝트가 쓰는 PC 봇. 원맥스에 포함 · 구매자에게 제공. 위 ①~④(Node.js·Claude Code·로그인)가 끝난 상태에서 진행하세요.

준비물
  • Python 3.11 이상 — python.org ("Add python.exe to PATH" 체크)
  • 한국투자증권 Open API 모의투자 키 — apiportal.koreainvestment.com 에서 발급(앱키·시크릿·계좌번호). 기본은 모의투자 모드.
  • 텔레그램 봇 — 텔레그램에서 @BotFather 로 봇 토큰 발급, 본인 채팅 ID. (매수 전 승인 알림에 씁니다)
B

봇을 둘 폴더에서 Claude Code 를 켜고 한 줄 붙여넣기

mkdir C:\트레이딩봇; cd C:\트레이딩봇; claude
https://www.waat.community/console/trading-bot.md 를 읽고, 그 안의 지시를 순서대로 전부 수행해서 트레이딩 봇을 설치·실행해줘

Claude Code 가 배포판을 내려받아 라이브러리 설치 → .env 에 키 입력(사용자가 값을 줄 때만) → 시험 기동까지 합니다. 증권사 로그인·키 발급·텔레그램 봇 생성은 대신 하지 않습니다.

URL 을 못 읽으면 trading-bot_v1.zip(148KB)을 받아 폴더에 풀고 "CLAUDE_CODE_봇설치지시문.md 파일을 읽고 그대로 수행해줘". 지시문 원문: trading-bot.md

이 봇은 투자 자문·일임이 아니며 샘플 전략은 교육용입니다. 승인 없이는 주문하지 않으며, 실계좌 전환은 README 의 절차를 읽고 본인이 결정합니다.

자주 막히는 3가지
'npm'은(는) 인식되지 않습니다

Node.js 설치 직후에 흔합니다. 터미널을 닫고 PC를 재부팅한 뒤 다시 하세요. 그래도 안 되면 Node.js 를 다시 설치(Repair)하세요.

로그인 화면(브라우저)이 안 뜹니다

터미널에 표시된 https://… 로 시작하는 주소를 복사해 브라우저 주소창에 직접 붙여넣으세요. 로그인 후 나오는 코드를 터미널에 붙여넣으면 됩니다.

검은 실행 창을 닫았더니 폰에서 연결이 끊깁니다

그 실행 창이 PC 쪽 서버입니다. 닫지 말고 최소화하세요. 닫았다면 작업 폴더에서 다시 claude 를 켜고 "원맥스 다시 실행해줘"라고 하면 됩니다. PC가 꺼져 있으면 아무것도 안 됩니다(PC가 서버).

이 앱은 투자 자문·일임이 아니며 샘플 전략은 교육용입니다. 페어링 코드와 PIN은 타인과 공유하지 마세요.
