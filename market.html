폰에서 내 PC의 Claude Code · Codex · Antigravity · Grok을 한 화면으로 지휘합니다. 회사에서, 이동 중에, 침대에서 — 폰으로 지시를 보내면 집·사무실 PC의 AI가 일하고, 결과가 말풍선으로 돌아옵니다.

AI 4종을 한 화면에

탭 하나로 전환. 한 AI의 답을 다른 AI에게 검토시키고 결과를 비교합니다.

진짜 내 PC를 움직입니다

폰에 쓴 글이 PC의 Claude Code 창에 그대로 타이핑되고, PC 창의 대화가 폰에 그대로 비칩니다. 파일을 읽고 쓰고 명령을 실행하는 실제 작업이 됩니다.

프로젝트 = 폴더, 무제한

폴더 하나가 프로젝트 하나. 트레이딩·블로그·논문·쇼핑몰… 폴더가 곧 지식베이스라 프로젝트끼리 섞이지 않습니다.

말로 만드는 전략

기본 프로젝트 "트레이딩 시그널" 동봉. 국내 주식 262종목 스캐너와 샘플 전략이 들어 있고, 조건을 문장으로 말하면 전략 파일·검증·백테스트까지 코드 0줄로 끝납니다.

사진·파일 전송, 남은 한도 표시

📎 하나로 카메라·파일을 올리면 AI가 바로 분석. Claude·Codex 구독의 5시간/7일 잔여 한도를 헤더에서 바로 봅니다.

가볍다 · 한 줄 설치

앱 1.4MB, 설치 10분, 추가 서버 비용 없음. PC에서 Claude Code를 켜고 설치 지시문 한 줄만 붙여넣으면 Claude Code가 설치를 대신 합니다.

구조 — PC가 서버, 앱은 화면

  • AI 대화·파일·시세·주문은 전부 사용자 PC 안에서만 오갑니다.
  • 우리 서버(허브)가 아는 것은 "어느 PC가 지금 어느 주소에 켜져 있나"뿐입니다. 저장 항목: 기기명·프로젝트명·접속 주소·마지막 확인 시각.
  • AI 사용료는 각자의 구독(Claude Pro/Max, ChatGPT 등)으로 처리됩니다. 이 앱은 AI 사용을 중개하거나 재판매하지 않습니다.

준비물

  • Windows PC(켜 두어야 함) + Node.js + Claude Code(필수). Codex·Antigravity·Grok은 선택.
  • 트레이딩 시그널의 2단계 정밀 신호·실매매는 본인의 증권사(한국투자증권) Open API 키가 필요합니다. 키가 없어도 1단계 스캔과 다른 모든 기능은 동작합니다.

솔직한 한계

  • PC가 꺼져 있으면 아무것도 안 됩니다(PC가 서버).
  • Claude Code 등 각 AI는 사용자가 직접 구독·로그인해야 합니다.
  • 현재 Windows PC + 안드로이드만. iOS·Mac은 다음 버전.
  • 무료 터널을 쓰면 PC를 켤 때마다 주소가 바뀌지만, 앱은 페어링 코드로 자동 추적합니다.

이 앱은 투자 자문·일임 서비스가 아니며, 동봉된 샘플 전략은 교육·출발점용입니다. 수익을 보장하지 않으며 모든 매매 판단과 결과는 사용자 본인의 책임입니다. 원격으로 PC를 움직이는 도구이므로 페어링 코드와 PIN을 타인과 공유하지 마세요.
