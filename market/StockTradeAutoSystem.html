매매 신호 발생은 프로그램이 하고, 매매 결정은 사람이 합니다.

1

승인 없이 매매 주문을 하지 않습니다

매수·매도 시점이 오면 텔레그램을 통해 종목과 근거를 제시해서 매수·매도 여부를 묻습니다. 승인하시면 주문합니다. 자동매매 설정을 하지 않는 한, 자리를 비우신 동안 승인 없이 매매 주문을 하지 않습니다.

2

신호·운영 규칙은 예시입니다

제작자의 신호 규칙 6개와 운영 규칙 7개 항목이 예시로 들어 있습니다. 신호 규칙은 스캐너 화면에서 규칙마다 켜고 끌 수 있고, 운영 규칙은 항목마다 값을 변경할 수 있습니다. 이 예시로 모의투자를 해 보시고, 본인에게 맞는 신호 규칙과 운영 규칙을 만들어 보세요.

이 규칙들은 국내 주식선물을 대상으로 뽑은 것입니다. 그래서 실제로 거래하시려면 선물옵션 계좌가 필요합니다 — 일반 주식 계좌로는 안 되고, 기본예탁금과 사전교육 이수가 조건입니다(조건과 금액은 증권사가 정합니다). 계좌 없이 모의투자로 먼저 돌려 보셔도 됩니다.

3

API 키는 내 PC 밖으로 나가지 않습니다

증권사 API 키와 계좌 번호는 내 PC 안에만 저장됩니다. 타인에게 제공되거나 다른 곳에 보관되지 않습니다. API 키 신청도 본인이 직접 합니다.
