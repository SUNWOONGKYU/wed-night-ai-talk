왜 CLI인가

챗봇은 밖에 있는 상담원.
CLI는 내 컴퓨터 안에 들어와 앉은 직원.

같은 AI라도 어디에 앉혀 놓고 사용하느냐가 다릅니다. 챗봇 사이트는 AI가 회사 창구에 있어서, 내가 서류를 들고 가서 보여주고 답을 받아 적어 와야 합니다. CLI(터미널)는 AI가 내 컴퓨터 안 내 방에 앉아서 내 서랍을 직접 열고 일합니다.

1. 심부름이 사라진다

챗봇은 파일을 올리고, 답을 복사하고, 내려받아 제자리에 넣는 일이 전부 내 몫입니다. CLI는 내 폴더 안에서 읽고, 수정하고, 그 자리에 저장합니다. 저장이 곧 완료. 보고서 100장을 수정하라고 하면 100장이 수정된 채로 그 폴더에 있습니다.

2. 손이 있다

챗봇은 "이렇게 하세요"라고 말만 합니다. CLI는 직접 합니다. 프로그램을 설치하고, 돌려 보고, 안 되면 수정하고, 다시 돌려 봅니다. 내 컴퓨터에 깔린 도구는 전부 사용합니다. 엑셀 정리, 사진 일괄 변환, 웹사이트 만들기, 주식 데이터 내려받기 — 말로 시키면 손으로 합니다.

3. 결과물이 바로 옆에 있다

웹사이트를 만들라고 하면 파일이 내 폴더에 생기고, PC에서는 그 자리에서 열립니다. 핸드폰에서는 콘솔 위쪽 버튼 하나로 그 사이트를 콘솔 안에서 바로 열어 눌러봅니다. 만든 페이지를 여는 버튼이 그 예입니다. 만들고 → 눌러보고 → "여기 수정해" → 다시 눌러보고. 이 순환이 핸드폰 한 화면에서 끝납니다. 버튼을 새로 다는 것도 말로 합니다.

방금 만든 랜딩페이지, 위쪽에 버튼으로 달아줘
"랜딩" 버튼을 달았습니다. 누르면 콘솔 안에서 바로 열립니다.

4. 몸이 가볍다

데스크톱 앱은 예쁜 화면을 그리려고 브라우저 한 벌을 통째로 안고 뜹니다. 그래서 무겁습니다. CLI는 글자만 주고받으니 그릴 게 없습니다. 켜는 데 0.1초, 앉아만 있을 땐 메모리 70MB 남짓. 그래서 한 컴퓨터에 AI 직원 수십 명을 앉혀 놔도 컴퓨터가 안 버벅입니다. 오래된 노트북, 켜 둔 채 두는 PC에서 차이가 납니다.

데스크톱 앱이 무거운 이유는 만드는 회사 문서에 그대로 적혀 있습니다: "웹브라우저와 구조가 거의 같다", "앱 창 하나마다 화면 그리는 프로세스가 따로 뜬다". 반대로 CLI는 화면 그리는 부분이 아예 없습니다.

5. 한 번 시킨 일을 저절로 돌게 할 수 있다

챗봇은 매번 내가 들어가서 말을 걸어야 합니다. CLI는 한 줄로 부를 수 있어서 "매일 아침 9시에 이거 해", "이 파일이 바뀌면 저거 해"처럼 걸어 두면 사람이 없어도 돕니다. 끝나면 성공인지 실패인지 신호를 남겨서, 실패하면 다시 시키거나 알림을 보내게 할 수 있습니다.

6. 넷 다 같은 모양이라 한 상에 앉힌다

Claude·OpenAI(Codex)·Google(Antigravity)·xAI(Grok) 네 회사가 전부 이 CLI 방식을 내놓았습니다. 모양이 같으니 나란히 두고 한 서버 밑에서 함께 일하게 할 수 있습니다. 앱이나 사이트였다면 넷을 한 화면에 묶기가 어렵습니다. One MACS가 "AI 4종"을 한 화면에 올릴 수 있는 이유가 바로 이것입니다.

왜 데몬인가

대화창을 띄워 마주 앉는 직원이 아니라,
쪽지만 주면 뒤에서 처리하고 결과만 놓고 가는 직원.

Claude Code만 대화창을 띄웁니다. Codex·Antigravity·Grok은 대화창 없이 뒤에서 자동으로 일하는 모드(헤드리스·데몬·백그라운드 프로세스 모드)로 돕니다. 데몬은 "대화창 없이 뒤에서 조용히 일하는 일꾼"이라는 뜻입니다.

1. 내 화면에 대화창이 안 뜬다

AI를 3개 더 켜도 PC 화면은 그대로입니다. 대화창 4개를 오가며 알트탭 할 일이 없습니다.

2. 물어보고 기다리지 않는다

대화창 직원은 "이거 해도 될까요?"를 묻고 내가 답할 때까지 멈춥니다. 데몬 직원은 정해진 방 안에서 끝까지 하고 결과만 놓고 갑니다. 그래서 지하철에서 시켜 놓고 도착하면 끝나 있습니다.

3. 일 없으면 자리를 비운다

사용할 때만 켜지고 끝나면 꺼집니다. 앉아서 컴퓨터 힘을 먹고 있는 시간이 0입니다.

4. 셋을 동시에 시켜도 된다

각자 따로 일하니 서로 기다리지 않습니다. Codex에는 검토, Antigravity에는 조사, Grok에는 초안 — 한 번에 던지고 한 번에 받습니다.

5. 결과가 정해진 서식으로 나온다

사람이 읽는 문장이 아니라 다음 직원이 바로 받아 사용할 수 있는 형식으로 내놓습니다. 그래서 Claude Code(메인)가 셋의 결과를 받아 종합하고, 다음 일로 넘길 수 있습니다.

6. 시킨 대로 했는지 기록이 남는다

주고받은 것이 전부 파일로 남습니다. 나중에 "그때 뭘 시켰고 뭘 했지"를 다시 열어볼 수 있습니다.

"물어보지 않는다"가 위험하지 않은 이유 — 데몬 직원은 정해진 방(프로젝트 폴더) 밖으로 못 나갑니다. 포맷·전체 삭제·컴퓨터 끄기 같은 위험한 일은 문 앞에서 막힙니다. 핸드폰의 🛑 긴급 정지 칩이 언제든 멈춥니다. 오래 걸리면 자동으로 정리됩니다. 그리고 전부 기록이 남습니다.

AI가 내 컴퓨터 안에서 일한다

올리고 내리는 심부름 없음. 수정하면 제자리에 저장. 결과물은 바로 옆에서 열어본다.

Claude Code를 중심으로 넷이 협업

"Codex한테 검토시켜", "셋 다 돌려 비교해". Claude Code가 역할을 나누고 결과를 모아 온다.

PC 여러 대, 코드 하나

집·사무실·노트북이 모바일 앱 위쪽에 나란히. 켜진 PC만 초록불.

주소가 바뀌지 않는다

PC마다 자기 주소를 하나씩. 껐다 켜도 같은 주소라 즐겨찾기에 넣어 두면 됩니다.

들어가는 문이 3개

PC 앞에서, Claude 앱에서, 이 콘솔에서. 어디서 말해도 같은 직원이 같은 일을 이어서.

API가 아닌 구독 요금제

4개 AI 전부 내 계정으로 로그인합니다. One MACS가 AI 요금을 따로 받지 않습니다.

설치는 Claude Code에게

설치 안내 주소를 Claude Code에 붙여 넣으면, Claude Code가 필요한 것을 물어보면서 설치를 진행합니다.

1핸드폰에서 조작할 수 없던 AI 3종을 조작합니다

Claude Code는 Remote Control이 있어 핸드폰에서 사용할 수 있습니다. 그런데 Codex·Antigravity·Grok CLI는 그런 기능이 없어서, PC 앞을 떠나면 시킬 수도 결과를 볼 수도 없습니다. (Codex는 ChatGPT 데스크톱 앱을 거치는 원격 기능이 있지만, Codex CLI 자체에서는 설정할 수 없습니다.) One MACS는 이 셋을 Claude Code와 같은 화면에서, 같은 방식으로 핸드폰에서 시키고 결과를 봅니다. 이 불편이 One MACS를 만들게 된 큰 계기 중 하나였습니다.

핸드폰에서 조작Claude Code: 공식 Remote Control ○ · Codex CLI: 공식 기능 없음(ChatGPT 데스크톱 앱 경유만) · Antigravity·Grok CLI: 공식 기능 없음 → One MACS로 ○

확인: 2026-09-21, 각 공식 문서 기준.

24개 AI 전부 터미널(CLI) 버전 — 가볍다, 숫자로

챗봇 창이 아니라 각 회사의 CLI입니다. CLI는 내 PC 파일을 직접 열어 수정하고 저장하고, 명령을 실행합니다. Claude Code 공식 문서도 터미널판을 "full-featured CLI"로 부르고, 다른 도구와 이어 붙여 자동으로 돌릴 수 있는 도구라고 적고 있습니다. 데스크톱 앱은 같은 엔진에 화면을 씌운 것이고, 웹 버전은 내 PC의 파일을 다루지 못합니다.

Claude Code CLI 세션 1개유휴 70~80MB · 작업 중 170~400MB (실측, Windows 11, 2026-09)
콘솔 서버 + 연결약 190MB · AI 3종(뒤에서 일하는 모드)은 부를 때만
CLI 기동0.12초 (실측 — 본문의 0.1초는 이 값)
비교: Windows 데스크톱 앱에이전트 모드를 켜면 실행할 때마다 1.8GB짜리 가상 PC(Hyper-V)가 같이 뜬다는 보도 (Neowin 2026-06-10, "CLI 사용자는 해당 없음")

모델 응답 속도는 같은 엔진이라 동일합니다. 차이는 껍데기가 먹는 메모리와 기동 시간이고, CLI에는 껍데기가 없습니다.

3대화창은 Claude Code 하나만 — 나머지는 헤드리스·데몬·백그라운드 프로세스 모드

Claude Code만 대화창을 띄웁니다. Codex·Antigravity·Grok은 대화창 없이 뒤에서 자동으로 일하는 모드로 실행됩니다. AI를 3개 더 켠다고 대화창이 3개 더 생기지 않습니다. 네 AI 모두 같은 프로젝트 폴더에서 파일을 읽고 저장하고 명령을 실행합니다.

설정에서 켜면 Claude·Codex 구독의 남은 한도(5시간/7일)가 상태줄에 표시됩니다.

4Claude Code를 중심으로 나머지 셋과 협업한다

Claude Code 하나에게만 말해도 됩니다. Claude Code가 중심이 되어 "이건 Codex에게 검토시켜", "셋 다 돌려서 비교해"처럼 역할을 나누고 결과를 종합합니다. 위임은 하나씩도, 셋 동시도 됩니다.

반대로 직접 작업을 시키고 싶으면 탭을 눌러 4개 AI에게 각각 동시에 다른 일을 시킬 수 있습니다. AI마다 따로 돌아가서 서로 기다리지 않습니다. Claude Code엔 구현, Codex엔 검토, Antigravity엔 조사, Grok엔 초안 — 한 번에.

방금 만든 전략 파일, Codex랑 Antigravity 둘 다에게 검토시켜서 다른 의견만 정리해줘
Codex·Antigravity에 동시 위임했습니다. (진행 중… 각 탭에서 확인 가능)
5진짜 내 PC 대화창을 움직인다 — 입력 경로 3개

핸드폰 채팅창에 입력한 글이 PC의 Claude Code 대화창에 그대로 타이핑되고, PC 대화창의 대화가 핸드폰에 그대로 비칩니다. 별도 세션이 아니라 평소 사용하던 그 대화창이라 내 프로젝트 폴더·설정·기록을 전부 아는 상태로 일합니다.

같은 세션에 들어가는 문이 셋입니다. ① PC 앞에서는 터미널, ② Anthropic 공식 Remote Control로 Claude 모바일 앱에서, ③ 이 콘솔. 어디서 넣든 한 Claude Code가 한 프로젝트를 이어서 일합니다.

대화는 요약 / 상세 / 전체 세 단계. 핸드폰에서는 요약만, PC에 앉으면 전체를. Remote Control은 Anthropic 기능이며 본인 Claude 구독으로 사용합니다.

6PC 여러 대 × 프로젝트 여러 개, 모바일 앱 하나

집 PC, 사무실 PC, 노트북 — 각각에 콘솔을 설치하고 같은 연결 코드를 사용하면 모바일 앱 상단에 PC 탭이 나란히 뜹니다. PC마다 자기 주소가 있고, 허브는 그중 지금 어느 PC가 켜져 있고 어느 프로젝트가 올라와 있는지를 알려 줍니다. 그래서 사무실 PC의 "분기보고서"와 집 PC의 "블로그"를 한 모바일 앱에서 오갑니다. 켜진 PC는 초록불, 꺼진 PC는 회색.

7프로젝트 = 폴더. 핸드폰에서 추가, 개수 제한 없음

폴더 하나를 등록하면 새 작업대가 생깁니다. 폴더가 곧 그 프로젝트의 자료 창고라 프로젝트끼리 섞이지 않습니다. 프로젝트마다 Claude Code가 따로 붙어서(첫 번째 프로젝트는 대화창, 그 외는 뒤에서 조용히) 지시가 다른 프로젝트로 새지 않습니다.

폴더가 없어도 됩니다. 콘솔 메뉴의 "＋ 프로젝트 추가"에 이름만 넣으면 PC에 그 이름의 폴더가 만들어지고, 거기서 새 Claude Code가 일을 시작합니다. 지하철에서 프로젝트를 새로 시작할 수 있습니다.

8따로 받으신 프로그램도 말 한마디로 붙습니다

메일로 받으신 프로그램을 폴더에 풀어 두고 Claude Code에게 「○○을 One MACS에 연결해줘」라고 말하면, 그 프로젝트가 목록에 생기고 모바일 앱 안에서 그대로 열립니다. 모바일 앱을 따로 설치하실 일도, 설정 파일을 손보실 일도 없습니다.

화면이 있는 프로그램이면 콘솔 위쪽에 여는 버튼까지 함께 답니다. 아래는 주식 매매 자동화 시스템을 연결해 둔 모습입니다 — 이 프로그램은 One MACS와 따로 파는 별도 상품이고, 출시 기념 한 달 동안은 메일로 함께 보내 드립니다.

10내 데이터는 내 PC에 — 허브는 주소만

11Claude Code 생태계가 통째로 핸드폰에 온다

껍데기 챗봇이 아니라 진짜 Claude Code 세션이라, PC에서 사용하던 것이 핸드폰에서도 전부 그대로입니다. 프로젝트의 CLAUDE.md, 세션마다 쌓이는 자동 메모리, 직접 만든 스킬(/전략만들기처럼), 훅, 외부 도구를 잇는 MCP, 작업을 쪼개 동시에 돌리는 서브에이전트 — 모두 공식 문서에 있는 기능이고 콘솔은 하나도 빼지 않습니다.

PC 대화창이 닫혀 있으면 지난 대화를 이어서 다시 띄웁니다. 어제 하던 대화가 오늘 핸드폰에서 계속됩니다.

13AI 4종에 심판이 있다 — Jev 판단 자문으로 팀처럼 돌아간다

여러 AI가 함께 일하면 "이 일은 누가 맡을지", "계속할지 멈출지", "결과가 된 건지", "얼마나 위험한지"를 누가 정하느냐가 문제입니다. One MACS에는 그 판단만 맡는 심판 Jev(제브)가 붙습니다. Jev는 MCP로 이어지고, 한 프로젝트에만 붙지 않습니다 — 콘솔이 만든 어느 프로젝트에서든, 어느 AI 채널에서든 같은 Jev를 부릅니다.

Jev가 답하는 것은 다섯 가지입니다.

① 누구에게 맡길까나·Codex·Antigravity·Grok·사람 중 누가 이 일에 맞는지
② 계속할까 멈출까다시 해볼지, 다른 AI에게 넘길지, 여기서 그만둘지
③ 결과가 된 건가끝났다고 보고하기 전에 완료 조건을 채웠는지
④ 얼마나 위험한가지우기·배포·결제·바깥으로 보내기처럼 되돌리기 어려운 일의 위험도
⑤ 그 밖의 좁은 판단고르기·점수·예/아니오 — 여러 질문을 한 번에 물어도 됩니다

Jev는 글도 코드도 만들지 않고, Claude Code가 물으면 "Codex에게 맡겨라(확률 0.8)", "결과 합격", "위험도 낮음"처럼 선택·점수·예/아니오만 답합니다.

그래서 Claude Code가 중심에서 셋을 나눠 부리고 결과를 모으는 협업이 사람 없이도 팀처럼 굴러갑니다. 판단이 애매하면(확률 0.6 미만) 사람에게 묻습니다. Jev는 사용자 본인의 Vercel AI Gateway 키로 동작하며(선택 설치), One MACS가 키를 대신 제공하지 않습니다.

확인: 콘솔 v1.9.53 · Jev MCP 도구 5종 · 사용자 범위로 등록되어 모든 프로젝트에서 부를 수 있음(실측 2026-09-24).

14내 PC끼리도 서로 일을 넘긴다

허브에 등록된 내 다른 PC의 어느 프로젝트든, 그 프로젝트의 Claude Code나 Codex·Antigravity·Grok에게 직접 지시하고 답을 받아 옵니다. 집 PC의 Claude Code가 사무실 PC의 조사 담당 프로젝트 Grok에게 "이 자료 정리해서 결론만"을 넘기고, 잠시 뒤 답을 받아 자기 일에 사용합니다. 결국 PC 여러 대의 AI 전부가 한 팀입니다.

핸드폰 콘솔과 똑같은 통로를 사용하므로 별도 설정이 없고, 상대 PC가 켜져 있으면 됩니다. 지금은 내 PC끼리(같은 허브 코드)까지이고, 다른 사람의 PC와 팀을 이루는 것은 다음 단계입니다.

확인: 콘솔 v1.8.6 이상(PC 간 지시·AI 지정) · 다른 PC의 Claude Code·Grok 실측 2026-09-23.

15말로 입력 — 키보드가 화면을 가리지 않습니다

입력창 옆 🎤 를 누르고 말하면 그대로 글이 됩니다. 키보드가 올라오지 않아 화면이 줄지 않고, 말하는 도중에도 글이 이어서 써집니다. 다 말한 뒤 보내기를 누르면 그때 전송되므로 잘못 말한 부분은 고쳐서 보낼 수 있습니다.

말하는 중에 잠깐 쉬어도 꺼지지 않습니다. 멈춤을 누를 때까지 계속 듣습니다(한 번에 최대 3분).

모바일 앱에서는 안드로이드 음성 인식(한국어)을, PC 브라우저에서는 크롬 음성 인식을 사용합니다. 둘 다 없는 환경에서는 버튼이 보이지 않습니다. 마이크 권한은 처음 한 번만 묻습니다.

확인: 콘솔 v1.8.4 · 모바일 앱 v1.5.1 이상 · 2026-09-23.

16내 PC끼리 파일과 글을 주고받는다

집 PC에서 만든 자료를 사무실 PC로 넘기는 일도 One MACS 안에서 끝납니다. 보내면 받는 PC가 켜져 있을 때는 곧바로 들어가고, 꺼져 있으면 지정해 둔 클라우드 폴더(원드라이브·구글 드라이브 등)를 거쳐 그 PC가 켜질 때 들어갑니다. 둘 다 준비돼 있으면 양쪽으로 보냅니다. 같은 것을 두 번 받지는 않습니다.

클라우드 폴더를 정하지 않아도 됩니다 — 그러면 켜져 있는 PC끼리 바로 주고받습니다. 받은 것은 PC마다 "받은함"에 날짜·보낸 PC·제목이 붙은 파일로 쌓여서 나중에 무엇을 언제 주고받았는지 그대로 남습니다. PC가 한 대뿐이면 이 기능은 화면에 나오지 않습니다.

확인: 콘솔 v1.8.7 · 직접 전송·클라우드 폴더 양쪽 실측 2026-09-23.

17모바일 앱으로도 사용하고 브라우저로도 사용합니다

마켓에서 받은 앱으로만 사용할 수 있는 다른 프로그램과 다릅니다. 모바일 앱은 설치본에 들어 있어 내 PC가 내려 주고, 거기에 더해 주소만 열면 어느 브라우저에서나 열립니다. PC 앞에서는 PC 브라우저로 크게 보고, 밖에서는 모바일 앱으로 알림을 받고, 남의 핸드폰에서는 브라우저로 엽니다. 아이폰·태블릿에서도 브라우저로 바로 사용합니다(모바일 앱은 안드로이드용). 말로 입력은 기기와 브라우저에 따라 다릅니다 — 지원하지 않으면 🎤 버튼이 보이지 않습니다.

여러 기기를 동시에 열어 두어도 서로 끊기지 않고, 어디서 열든 같은 대화가 이어집니다. 핸드폰에서 시켜 놓고 PC 브라우저에서 이어 봐도 됩니다. 기능의 본체가 PC 안의 콘솔이고 모바일 앱과 브라우저는 그것을 비추는 화면이기 때문입니다.

모바일 앱을 설치하십시오. 주소창이 없어 화면이 그만큼 넓어서 보기가 훨씬 낫습니다. 그 밖에 모바일 앱에만 있는 것이 셋 — 작업이 끝났을 때 알림, PIN 번호 자동 로그인, 말로 입력. 브라우저는 모바일 앱을 설치할 수 없는 기기(아이폰·태블릿·남의 폰)에서 사용하시면 됩니다.

확인: 콘솔 v1.9.1 · 모바일 앱 v1.5.1 · 세 기기 동시 접속 실측 · 사파리 엔진 실측(아이폰 15 크기) 2026-09-23.

18접속 주소가 바뀌지 않습니다 — PC마다 자기 주소

전에는 PC를 다시 켤 때마다 접속 주소가 새로 생겼습니다. 그때그때 빌려 사용하는 무료 통로였기 때문입니다. 지금은 PC마다 자기 주소를 하나씩 받습니다 — 6mr2f6-3.onemacs.com 처럼 받으신 코드가 앞에 붙은 모양입니다. 껐다 켜도, 며칠 뒤에도 같은 주소입니다.

그래서 주소를 즐겨찾기에 넣어 두고 바로 열 수 있고, 연결이 훨씬 덜 끊깁니다. 전에 사용하던 무료 통로는 끊겨도 보장이 없는 등급이었습니다.

주소가 고정돼도 허브는 그대로 필요합니다. 내 PC가 몇 대인지, 지금 어느 PC가 켜져 있는지, 어느 PC에 무슨 프로젝트가 있는지 — 주소만으로는 알 수 없고 허브가 알려 줍니다. 주소가 고정이라고 그 PC가 켜져 있다는 뜻은 아니기 때문입니다.

안전장치도 있습니다. 고정 주소가 제때 서지 않으면 콘솔이 스스로 예전 방식으로 물러서서 계속 동작합니다. 멈추지 않습니다.

확인: 콘솔 v1.9.53 · 고정 주소 실패 시 자동 전환 실측 2026-09-23 · 실제 발급된 주소로 접속 확인 2026-09-24.

설치

Claude Code가 있다면,
설치는 Claude Code에게 지시하면 됩니다.

One MACS 폴더의 CLAUDE_CODE_지시문.md 를 읽고, 그 안의 지시를 순서대로 전부 수행해서 One MACS 를 이 PC 에 설치해줘.

받은 설치본(zip)을 아무 폴더에나 풀고, 그 폴더에서 Claude Code를 켜 위 한 줄을 붙여 넣습니다. Claude Code가 함께 사용할 AI·모델·프로젝트를 물어본 뒤 설치·서버 켜기·연결·연결 코드 발급까지 진행하고, 연결 코드와 이 PC의 고정 주소를 알려 줍니다. 공유기 설정이나 포트 열기는 필요 없습니다. 사람이 하는 일은 질문에 답하고, 받은 코드를 핸드폰에 넣는 것입니다.

1PC — 배포판을 받아 아무 폴더에나 풉니다. 준비물은 Windows PC(켜 두어야 함) + Node.js + Claude Code(본인 구독). 아직 없다면 irm https://claude.ai/install.ps1 | iex 한 줄로 설치.
2PC — 푼 폴더에서 Claude Code를 켜고 위 한 줄을 붙여 넣습니다. 끝나면 연결 코드 8자리와 이 PC의 고정 주소를 알려 줍니다.
3핸드폰 — 브라우저로 그 고정 주소를 열고 연결 코드와 PIN 번호을 넣습니다. 그러면 내 PC의 프로젝트 목록과 AI 4개 탭이 화면에 뜨고, 그 자리에서 일을 시킬 수 있습니다.
4모바일 앱 설치 — ⚙ 설정에서 [앱 받기]를 누르면 내 PC가 모바일 앱을 내려 줍니다. 마켓에서 따로 받지 않습니다. 설치가 끝나면 주소창이 없어져 화면이 그만큼 넓어집니다. 작업이 끝났을 때 알림, PIN 번호 자동 로그인, 말로 입력도 모바일 앱에서만 됩니다.
자주 묻는 질문

PC가 꺼져 있으면?

아무것도 안 됩니다. PC가 서버이고 모바일 앱은 화면이기 때문입니다. 출근 전에 PC를 켜 두거나 절전을 끄는 것이 전부입니다. 대신 그 덕분에 대화·파일이 우리 서버에 남지 않습니다.

AI 구독이 포함되나요? API 요금은?

구독은 포함되지 않습니다. Claude Code(필수)·Codex·Antigravity·Grok은 사용자가 직접 구독하고 PC에서 로그인합니다. 전부 계정 로그인 방식이라 API가 아닌 구독 요금제를 사용합니다(Antigravity는 Google 계정 무료 플랜부터). 9,900원은 소프트웨어 값이며 One MACS는 AI 사용을 중개·재판매하지 않습니다. PC마다 주는 고정 주소와, 핸드폰이 내 PC를 찾아 주는 허브는 첫 3개월이 포함되고, 그 뒤에도 계속 사용하려면 1년 9,900원입니다 — 직접 만들어 사용하면 무료입니다(받으신 파일 안에 만드는 방법과 프로그램이 들어 있습니다).

Remote Control이 있는데 왜 필요하죠?

Claude 하나만, PC 한 대의 세션을 핸드폰에서 이어서 사용하는 게 목적이면 Remote Control로 충분합니다. One MACS는 Codex·Antigravity·Grok 탭, Claude Code를 중심으로 한 협업, 핸드폰에서 프로젝트 폴더 생성, PIN 번호 잠금·긴급 정지를 그 위에 얹습니다. 위 비교표를 보세요.

아이폰·Mac은?

모바일 앱은 안드로이드용이고, 아이폰·Mac에서는 브라우저로 지금도 사용할 수 있습니다(같은 주소·같은 PIN 번호). 말로 입력은 기기와 브라우저에 따라 다릅니다 — 지원하지 않으면 🎤 버튼이 보이지 않습니다. PC는 Windows만 지원하며 다른 운영체제는 준비 중입니다.

PC를 켤 때마다 주소가 바뀌나요?

아닙니다. PC마다 자기 주소를 하나씩 받아, 껐다 켜도 같은 주소입니다. 즐겨찾기에 넣어 두고 바로 열면 됩니다. 모바일 앱은 연결 코드로 내 PC를 찾아가므로 주소를 외울 일도 없습니다.
