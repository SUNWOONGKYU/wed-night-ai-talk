자주 묻는 질문

자주 막히는 10가지

대부분은 PC의 검은 실행 창(1클릭_실행.bat)과 C:\원맥스\_mobile_remote 폴더 안에서 해결됩니다. 아래에서 해당 항목을 여세요.

어느 항목이든 그래도 안 되면 PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요. 배포판에 동봉된 원맥스_진단.md 를 읽고 원인을 찾아 알려줍니다.
1. 원맥스는 PC 어디에 설치되나요?

설치 안내대로 했다면 C:\원맥스 입니다. 그 안의 _mobile_remote 폴더가 콘솔 본체(핸드폰과 연결되는 부분)이고, 트레이딩 시그널 같은 프로젝트 폴더가 옆에 놓입니다.

다른 폴더에 설치했다면 Claude Code 를 켰던 그 폴더입니다. 설정 파일은 항상 <설치 폴더>\_mobile_remote\console_config.json 입니다.

그래도 안 되면 PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요.

2. PIN 을 잊었어요

PC의 C:\원맥스\_mobile_remote\console_config.json 파일을 메모장으로 열면 "pin": "숫자" 줄이 있습니다. 그 숫자가 PIN 입니다.

바꾸고 싶으면 그 값을 새 숫자로 고쳐 저장하고, 검은 실행 창을 닫았다가 1클릭_실행.bat 으로 다시 켜세요. 파일을 직접 만지기 부담스러우면 PC의 Claude Code 에 "PIN 바꿔줘" 라고 해도 됩니다.

그래도 안 되면 PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요.

3. 페어링 코드가 안 떠요

페어링 코드는 PC가 인터넷 터널(cloudflared)에 연결된 뒤에 나옵니다. 실행 후 보통 5~30초, 길면 1분까지 기다려 보세요. 코드는 C:\원맥스\_mobile_remote\페어링코드.txt 첫 줄에도 저장됩니다.

1분이 지나도 없으면 순서대로 확인합니다: ① PC가 인터넷에 연결되어 있는지 ② _mobile_remote 폴더에 cloudflared.exe 가 있는지 ③ 검은 실행 창에 빨간 오류 줄이 있는지(백신·방화벽이 cloudflared 를 막는 경우가 있습니다 → 허용).

그래도 안 되면 PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요.

4. Claude Code(또는 Codex·Antigravity·Grok) 를 업데이트했더니 안 돼요

CLI 를 업데이트하면 로그인이 풀리거나 실행 방식이 바뀌는 경우가 있습니다. 먼저 터미널에서 해당 CLI 를 직접 한 번 켜서(claude 등) 로그인이 살아 있는지 확인하고, 검은 실행 창을 닫았다가 1클릭_실행.bat 으로 다시 켜세요.

특정 버전과 맞지 않는 경우는 앱이 알려줍니다(원맥스가 호환 안내를 확인합니다). 안내가 뜨면 그 내용대로 하세요.

그래도 안 되면 PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요.

5. 잘 쓰다가 갑자기 핸드폰에서 연결이 끊겨요 (터널 끊김)

PC의 인터넷이 잠깐 끊기거나 절전 모드에 들어가면 터널이 끊깁니다. PC를 깨우고 인터넷을 확인한 뒤, 앱에서 PC 탭을 다시 열어 보세요. 대부분 자동으로 다시 붙습니다.

계속 안 되면 검은 실행 창을 닫고 1클릭_실행.bat 으로 다시 켜세요. 페어링 코드와 PIN 은 그대로입니다. 노트북이라면 전원 옵션에서 절전 모드를 끄면 재발이 줄어듭니다.

그래도 안 되면 PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요.

6. AI 가 "사용 한도를 초과했습니다" 라고 해요

원맥스는 각 AI 를 사용자 본인의 구독으로 씁니다. 한도는 원맥스가 아니라 그 AI 의 구독(Claude·Codex·Antigravity·Grok)에서 정해집니다. 앱 헤더의 남은 한도 표시를 확인하고, 한도가 풀리는 시각까지 기다리거나 다른 AI 탭으로 이어서 작업하세요.

자주 한도에 걸리면 그 AI 의 상위 요금제를 사용하거나, 대화창 없이 뒤에서 도는 AI 로 일을 나누는 방법이 있습니다. 원맥스는 AI 사용료를 받거나 중개하지 않습니다.

그래도 안 되면 PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요.

7. 검은 실행 창을 닫았더니 핸드폰에서 안 돼요

그 실행 창이 PC 쪽 서버입니다. 닫으면 연결이 끊깁니다. C:\원맥스\_mobile_remote\1클릭_실행.bat 을 다시 실행하면 됩니다(프로젝트 창도 자동으로 뜹니다). 다음부터는 닫지 말고 최소화하세요.

그래도 안 되면 PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요.

8. PC 가 꺼져 있을 때도 핸드폰에서 쓸 수 있나요?

아니요. PC 가 서버라서 PC 가 켜져 있고 실행 창이 떠 있어야 합니다. 밖에서 쓰려면 PC 를 켜 두고 절전 모드를 끄세요. PC 가 꺼져 있으면 앱의 PC 탭에 "연결 안 됨"으로 표시됩니다.

그래도 안 되면 PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요.

9. PC 를 여러 대 등록하고 싶어요

PC 마다 같은 설치 안내를 한 번씩 하면 됩니다(PC 마다 페어링 코드가 따로 나옵니다). 앱에서 새 페어링 코드를 입력하면 PC 탭이 하나 더 생기고, 탭을 눌러 오가며 각 PC 의 프로젝트를 씁니다. PC 이름표는 설치할 때 정하거나, 그 PC 의 Claude Code 에 "PC 이름표 바꿔줘" 라고 하면 바뀝니다.

그래도 안 되면 PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요.

10. 앱을 지웠다 다시 설치했더니 PIN 을 또 물어봐요

정상입니다. 앱을 다시 설치하면 핸드폰에 저장된 PC 목록과 PIN 이 지워집니다. 페어링 코드(페어링코드.txt 첫 줄)를 다시 입력하고, PC 탭을 처음 열 때 PIN 을 한 번 더 입력하면 됩니다. PC 쪽은 아무것도 바꿀 필요가 없습니다. 라이선스 키는 구매 메일에 있습니다.

그래도 안 되면 PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요.

그래도 안 되면

① PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요 (동봉된 원맥스_진단.md 를 수행합니다)
② 이 페이지의 10가지를 다시 확인하세요
③ 앱의 문제 신고 메일로 보내 주세요

페어링 코드와 PIN 은 타인과 공유하지 마세요. 보안·권한·잠금에 관한 내용은 알아 두실 점에 있습니다.
