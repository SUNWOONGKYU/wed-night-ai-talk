PC에 원맥스 설치하기

모바일 앱에서 오셨나요? 여기서 3단계만 하면 폰에 넣을 코드 8자리가 나옵니다.

PC에 원맥스를 설치하는 일은
Claude Code가 대신 합니다.

사람이 할 일은 Node.js 설치 → Claude Code 설치·로그인 → Claude Code에게 설치 지시입니다. 지시하면 Claude Code가 필요한 것(어떤 AI를 함께 쓸지, 모델, 프로젝트)을 물어보면서 설치를 진행합니다.

지금 폰으로 보고 계시네요. 아래 단계는 Windows PC에서 해야 합니다. PC 브라우저에서 waat.community/console 을 열면 각 단계에 [복사] 버튼이 나옵니다.
이미 Claude Code가 있으면

⑤ C:\원맥스 폴더에서 claude 실행 → ⑥ 설치 지시문 붙여넣기 → Claude Code의 질문에 답하기.

1

Node.js LTS 설치

https://nodejs.org 에서 LTS 버전을 받아 설치합니다. 설치 화면은 전부 "Next"로 넘기면 됩니다.

설치가 끝나면 PC를 한 번 재부팅하세요. (재부팅 안 하면 다음 단계에서 npm을 못 찾는 경우가 많습니다)

2

터미널 열기

Windows 시작 버튼 → "터미널" 입력 → 실행 (없으면 "PowerShell").

검은(또는 파란) 실행 창에 커서가 깜빡이면 준비된 것입니다.

이 실행 창은 설치가 끝날 때까지 닫지 마세요.

3

Claude Code 설치

아래 명령을 복사해 터미널에 붙여넣고 Enter.

npm install -g @anthropic-ai/claude-code

1~2분 걸립니다. 'added … packages' 가 나오면 성공.

4

로그인

터미널에 claude 를 입력하고 Enter → 브라우저가 열리면 Anthropic 계정(Claude Pro/Max 구독)으로 로그인 → 터미널로 돌아옵니다.

claude

Claude Code는 Claude 구독이 있어야 사용할 수 있습니다. 구독이 없으면 claude.ai 에서 Pro 이상을 먼저 결제하세요. 로그인이 끝났으면 /exit 로 일단 나옵니다.

5

C:\원맥스 폴더를 만들고 그 안에서 Claude Code 실행

원맥스가 설치될 폴더입니다. PowerShell(또는 터미널)에 아래를 붙여넣으면 폴더가 만들어지고 그 안에서 Claude Code가 켜집니다.

mkdir C:\원맥스; cd C:\원맥스; claude

다른 폴더를 사용하고 싶으면 cd 그폴더; claude. 설치가 끝나면 이 폴더 안에 _mobile_remote(콘솔)와 "트레이딩 시그널"(기본 프로젝트) 폴더가 생깁니다.

6

Claude Code에게 설치를 지시하기

받으신 파일을 푼 폴더에서 Claude Code를 켜고, 아래 한 줄을 붙여넣고 Enter. 이후 Claude Code가 물어보는 것에 답하면 됩니다.

One MACS 폴더의 CLAUDE_CODE_지시문.md 를 읽고, 그 안의 지시를 순서대로 전부 수행해서 One MACS 를 이 PC 에 설치해줘.

이후는 Claude Code가 알아서 합니다: 설치 · 설정 · 실행 · 연결 코드 발급. 중간에 로그인이나 확인을 물으면 답해 주세요. 끝나면 연결 코드 8자리와 이 PC의 고정 주소를 알려줍니다.

나중에 새 판이 나오면 같은 자리에서 "One MACS 폴더의 CLAUDE_CODE_지시문.md 의 「2부 업데이트」대로 One MACS 업데이트해줘."라고 하시면 됩니다. 자세한 것은 함께 들어 있는 One MACS 사용설명서에 있습니다.

7

폰: 모바일 앱 열고 연결 코드 입력 → 끝

모바일 앱(/market/onemacs)을 설치한 폰에서 원맥스를 열고, PC가 알려준 연결 코드 8자리를 입력하면 연결됩니다. 이후 PC가 켜져 있으면 어디서든 핸드폰에서 작업을 시킬 수 있습니다.

설치가 끝나면 사용법: waat.community/market/onemacs/guide (허브·모바일 앱의 ⓘ 버튼으로도 열립니다)

함께 보내 드리는 프로그램

주식 매매 자동화 시스템 패키지는 이메일로 따로 보내 드립니다.

One MACS를 구매하신 분께는 2026년 10월 25일까지 주식 매매 자동화 시스템 패키지와 보고서 작성 에이전트 패키지를 무료로 보내 드립니다. 따로 결제하거나 신청하실 필요는 없습니다.

B

받으시면 — 폴더에 풀고 한 줄

받으신 파일을 독립된 폴더에 푸시면 그 안에 설명서 한 장과 Claude Code용 지시문 한 장이 함께 있습니다. 그 폴더에서 Claude Code를 켜고 아래 한 줄을 붙여넣으십시오.

이 폴더의 CLAUDE_CODE_지시문.md 를 읽고, 그 안의 지시를 순서대로 전부 수행해줘.

설치가 끝난 뒤 「주식 매매 자동화 시스템을 One MACS에 연결해줘」라고 하시면 모바일 앱 안에서 그대로 열립니다.

증권사 키 발급·텔레그램 봇 만들기는 본인이 하십니다. 준비물과 한계는 주식 매매 자동화 시스템 판매면에 정리해 두었습니다. 승인 없이는 주문하지 않습니다.

자주 막히는 3가지
'npm'은(는) 인식되지 않습니다

Node.js 설치 직후에 흔합니다. 터미널을 닫고 PC를 재부팅한 뒤 다시 하세요. 그래도 안 되면 Node.js 를 다시 설치(Repair)하세요.

로그인 화면(브라우저)이 안 뜹니다

터미널에 표시된 https://… 로 시작하는 주소를 복사해 브라우저 주소창에 직접 붙여넣으세요. 로그인 후 나오는 코드를 터미널에 붙여넣으면 됩니다.

검은 실행 창을 닫았더니 폰에서 연결이 끊깁니다

그 실행 창이 PC 쪽 서버입니다. 닫지 말고 최소화하세요. 닫았다면 작업 폴더에서 다시 claude 를 켜고 "원맥스 다시 실행해줘"라고 하면 됩니다. PC가 꺼져 있으면 아무것도 안 됩니다(PC가 서버).

더 많은 경우(PIN 번호 을 잊었을 때 · 연결 코드가 안 뜰 때 · 터널 끊김 · 여러 PC 등록 등)는 자주 묻는 질문 10가지에 있습니다. 문제가 생기면 먼저 PC의 Claude Code 에 "원맥스 진단해줘" 라고 하세요.

연결 코드와 PIN 번호은 타인과 공유하지 마세요. 보안·권한·잠금에 관한 내용은 알아 두실 점에 있습니다.
