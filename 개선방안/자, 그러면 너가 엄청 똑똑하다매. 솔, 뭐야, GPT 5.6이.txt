네, 가능합니다. 현재 이 Work 세션에 연결된 작업 디렉토리라면 절대경로만 알려주시면 제가 코드 전체를 직접 읽고 분석할 수 있습니다. 배포된 사이트를 볼 필요가 없습니다.
다만 구분해야 합니다.
이 세션의 워크스페이스에 이미 들어온 폴더: 경로만 알려주시면 바로 접근 가능

로컬 프로젝트를 이 워크스페이스에 연결하거나 ZIP으로 올리면 접근 가능
Git 저장소가 연결돼 있다면 저장소 안에서 직접 분석 가능
데스크톱 버전만 가능하다기보다, 해당 폴더가 현재 Work 세션에 공유·마운트되어 있느냐가 핵심입니다. 모바일에서는 프로젝트 폴더 전체를 ZIP으로 올리는 방식이 간편하고, 데스크톱에서는 작업 폴더를 연결하는 방식이 편합니다.

필요한 것은 소스코드, 설정파일, DB 스키마, 주요 문서입니다.
작업 디렉토리가 이미 연결돼 있다면 절대경로를 그대로 알려주세요. 제가 먼저 전체 파일 구조와 기술스택을 파악하고, 기존 기능을 보존하면서 WAAT.community 전면 개편안을 코드 기준으로 다시 만들겠습니다.

써니님이 지금 사용하는 안드로이드 모바일 앱에서는 PC의 로컬 폴더를 직접 연결할 수 없습니다. 별도의 업로드 경로를 입력하는 방식도 아닙니다. 로컬 폴더 연결은 Windows·Mac용 ChatGPT 데스크톱 앱에서만 지원됩니다. OpenAI 공식 안내

WAAT.community는 전체 코드와 DB 구조를 봐야 하므로 PC용 ChatGPT 앱 → Work → 로컬 폴더 열기가 가장 좋습니다. 그러면 제가:

까지 같은 작업 폴더에서 진행할 수 있습니다. 입력할 특별한 경로가 있는 게 아니라, 데스크톱 앱에서 폴더 선택창을 열어 WAAT.community 프로젝트 폴더를 고르는 방식입니다.
