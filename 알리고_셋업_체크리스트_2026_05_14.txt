WAAT 알리고 SMS/알림톡 — 사전 셋업 체크리스트
작성: 2026-05-14
소요: 약 2~5일 (카카오 검수 대기 포함)
============================================

⚠️ 이메일(Resend) 시스템부터 먼저 배포한 후 진행하세요.
   알리고는 외부 인증·검수 절차가 많아 코드만으로 완결되지 않습니다.


[1단계] 알리고 계정 가입 (당일)
--------------------------------------------
[ ] https://smartsms.aligo.in/ 접속
[ ] 회원가입
[ ] 사업자 인증 OR 개인 인증 (둘 중 하나)
    · 개인: 본인 명의 휴대폰 인증으로 가능
    · 사업자: 사업자등록증 필요 (단가 약간 저렴)
[ ] 충전 (1만원 권장 — 테스트용)


[2단계] 발신번호 등록 (1일 소요)
--------------------------------------------
[ ] 알리고 마이페이지 → 발신번호 관리
[ ] 본인 명의 휴대폰 번호 입력 → SMS 인증
[ ] 또는 사업자 명의 유선번호 + 통신서비스 가입증명원 업로드
[ ] 승인까지 영업일 기준 1일 대기


[3단계] 카카오톡 비즈채널 생성 (1일 소요)
--------------------------------------------
[ ] https://center-pf.kakao.com 접속 (카카오 비즈니스)
[ ] 채널 만들기 → 채널명 입력
    추천: "WAAT" 또는 "수요일 오후 AI 수다"
[ ] 채널 URL: @waat 또는 @wed-ai-talk
[ ] 카카오톡 채널 비즈니스 인증 신청
    · 개인사업자/법인사업자 인증서 필요
    · 통신판매업 신고증 (선택)
[ ] 인증 승인 대기 (영업일 1일)


[4단계] 알림톡 신청 + 알리고 연동 (1일 소요)
--------------------------------------------
[ ] 카카오 비즈센터 → 알림톡 신청
[ ] 발송 대행사로 "알리고" 선택
[ ] 알리고와 채널 연동 등록
    · 알리고 → 카카오 알림톡 메뉴 → 채널 추가
    · 채널 검색 키 + 카카오 인증 코드 입력


[5단계] 알림톡 템플릿 등록 (1~2일 검수)
--------------------------------------------
6종 템플릿 등록 후 카카오 검수 통과 필요

[ ] T1. 가입 환영
[ ] T2. 신청 확인 (회차/슬롯/장소 포함)
[ ] T3. D-3 리마인더
[ ] T4. D-1 리마인더
[ ] T5. 신청 취소 확인
[ ] T6. 일반 공지 (관리자 수동)

* 문구 초안은 SMS_운영방안_2026_05_10.md 참고
* 광고성 문구 금지, 변수는 #{변수명} 형식 사용
* 통과율 향상 팁:
  · 인사말 명확히 (예: "[WAAT] {이름}님,")
  · 모임 정보를 명확히 (날짜/시간/장소)
  · 변수 위치를 일관되게 유지


[6단계] API Key 발급
--------------------------------------------
[ ] 알리고 마이페이지 → API 키 관리
[ ] User ID 확인 (보통 가입 ID)
[ ] API Key 발급 (re_xxxx 아님, 알리고 전용 키)
[ ] ⚠️ 키를 채팅에 붙여넣지 말 것!
    .env 파일에만 저장 (ALIGO_API_KEY, ALIGO_USER_ID, ALIGO_SENDER)
[ ] Supabase secrets 에도 동일하게 등록 예정 (배포 시점)


[7단계] 모든 셋업 완료되면 알려주세요
--------------------------------------------
1~6단계 완료되면 Claude에게 "알리고 셋업 완료" 한 마디.
그러면 다음 작업 진행:
  · DB 마이그레이션 (message_logs, members.*_optin)
  · Edge Function send-notification 작성
  · admin "메시지 발송" 탭
  · 자동 트리거 (가입/신청/취소 이벤트)
  · D-3, D-1 리마인더 Cron
