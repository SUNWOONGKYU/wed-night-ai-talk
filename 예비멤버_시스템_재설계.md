# WAAT 예비 멤버 시스템 (비밀번호 없음)

## 1. 개요

**111명의 연락처를 "예비 멤버" DB에 등록**
→ 비밀번호 없이 이메일로만 신원 확인
→ 자신의 정보를 직접 입력 + 비밀번호 설정
→ 정식 회원으로 전환

**"회원"이 아닌 "예비 멤버"** (아직 가입 완료 안 됨)

---

## 2. DB 스키마

### 2.1 새로운 테이블: `provisional_members`

```sql
CREATE TABLE provisional_members (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) NOT NULL UNIQUE,
    name VARCHAR(255) NOT NULL,
    source VARCHAR(50),  -- '페이스북', '카톡_댓글', '카톡_본문'
    created_at TIMESTAMP DEFAULT now(),
    submitted_at TIMESTAMP  -- 정보 입력 완료 시간
);
```

### 2.2 "정식 회원"은 기존 `profiles` + `auth.users` 사용

```sql
-- 정식 회원이 되려면:
INSERT INTO auth.users (
    email, 
    encrypted_password,  -- 사용자가 직접 설정
    confirmed_at, 
    raw_user_meta_data
) VALUES (...);

INSERT INTO profiles (
    id, 
    email, 
    name, 
    phone, 
    bio, 
    interests
) VALUES (...);
```

```javascript
// admin.js
async function importProvisionalMembers(csvData) {
    // 기존 회원 이메일 조회 (중복 방지)
    const existingEmails = await DB.getExistingEmails();
    
    // 111명 중 미등록자만 필터링
    const newMembers = csvData.filter(row => 
        !existingEmails.includes(row.email)
    );
    
    console.log(`✓ 추가 등록: ${newMembers.length}명`);
    console.log(`⚠️ 중복(기존 회원): ${csvData.length - newMembers.length}명`);
    
    // DB 삽입
    await DB.insertProvisionalMembers(newMembers);
}
```

### 단계 3️⃣: 예비 멤버 확인

**join.js - 이메일로 예비 멤버 조회:**

```javascript
const joinForm = {};

async function checkProvisionalEmail() {
    const email = document.getElementById('join-email').value.trim();
    
    if (!email) {
        alert('이메일을 입력하세요');
        return;
    }
    
    try {
        // 예비 멤버 테이블에서 조회
        const provisional = await DB.getProvisionalMember(email);
        
        if (!provisional) {
            alert('예비 멤버 목록에 없습니다.\n운영자에게 문의하세요.');
            return;
        }
        
        // 기존 회원인지 체크
        const existing = await DB.getExistingMember(email);
        if (existing) {
            alert('이미 가입한 회원입니다.\n로그인 해주세요.');
            return;
        }
        
        // 예비 멤버 정보 표시
        joinForm.provisionalId = provisional.id;
        joinForm.email = email;
        
        document.getElementById('join-prov-id').value = provisional.id;
        document.getElementById('join-name').value = provisional.name;
        document.getElementById('join-form-main').style.display = 'block';
        
        console.log(`✓ 예비 멤버 확인: ${provisional.name} (${email})`);
        
    } catch (e) {
        console.error('Error:', e);
        alert('오류가 발생했습니다: ' + e.message);
    }
}

async function submitJoin() {
    const phone = document.getElementById('join-phone').value.trim();
    const bio = document.getElementById('join-bio').value.trim();
    const interests = document.getElementById('join-interests').value.trim();
    const password = document.getElementById('join-password').value;
    
    // 필수 필드 확인
    if (!phone || !password) {
        alert('전화번호와 비밀번호는 필수입니다');
        return;
    }
    
    if (password.length < 8) {
        alert('비밀번호는 8자 이상이어야 합니다');
        return;
    }
    
    try {
        // 1단계: Supabase 계정 생성 (password 포함)
        const { user, error } = await Auth.signUp({
            email: joinForm.email,
            password: password
        });
        
        if (error) throw error;
        
        // 2단계: 프로필 생성
        await DB.createProfile({
            id: user.id,
            email: joinForm.email,
            name: document.getElementById('join-name').value,
            phone: phone,
            bio: bio,
            interests: interests
        });
        
        // 3단계: 예비 멤버 마크 (submitted_at 업데이트)
        await DB.markProvisionalSubmitted(joinForm.provisionalId);
        
        alert('✅ 가입이 완료되었습니다!\n로그인 해주세요.');
        window.location.href = 'index.html';
        
    } catch (e) {
        console.error('Join error:', e);
        alert('가입 중 오류: ' + e.message);
    }
}

// 버튼 바인딩
document.addEventListener('DOMContentLoaded', function() {
    document.getElementById('btn-check-email').addEventListener('click', checkProvisionalEmail);
    document.getElementById('btn-submit-join').addEventListener('click', submitJoin);
});
```

### 단계 4️⃣: 정식 회원으로 전환

**DB.js (Supabase 함수 추가):**

```javascript
const DB = {
    // ... 기존 함수들 ...
    
    // 예비 멤버 조회
    async getProvisionalMember(email) {
        const { data, error } = await supabase
            .from('provisional_members')
            .select('*')
            .eq('email', email)
            .single();
        if (error && error.code !== 'PGRST116') throw error;
        return data || null;
    },
    
    // 모든 예비 멤버 조회
    async getAllProvisionalMembers() {
        const { data, error } = await supabase
            .from('provisional_members')
            .select('*')
            .is('submitted_at', null);  // 미제출자만
        if (error) throw error;
        return data;
    },
    
    // 예비 멤버 일괄 등록
    async insertProvisionalMembers(members) {
        const { data, error } = await supabase
            .from('provisional_members')
            .insert(members);
        if (error) throw error;
        return data;
    },
    
    // 예비 멤버 제출 완료 마킹
    async markProvisionalSubmitted(provisionalId) {
        const { data, error } = await supabase
            .from('provisional_members')
            .update({ submitted_at: new Date() })
            .eq('id', provisionalId);
        if (error) throw error;
        return data;
    }
};
```

```javascript
async function loadProvisionalStats() {
    const allProv = await DB.getAllProvisionalMembers();
    const submitted = allProv.filter(p => p.submitted_at).length;
    const pending = allProv.length - submitted;
    
    document.getElementById('stat-total-prov').textContent = allProv.length;
    document.getElementById('stat-submitted-prov').textContent = submitted;
    document.getElementById('stat-pending-prov').textContent = pending;
    
    // 미제출 목록 표시
    const html = pending > 0 ? 
        allProv
            .filter(p => !p.submitted_at)
            .map(p => `
                <tr>
                    <td>${p.email}</td>
                    <td>${p.name}</td>
                    <td>${p.source || '—'}</td>
                    <td>${new Date(p.created_at).toLocaleDateString('ko-KR')}</td>
                    <td>
                        <button class="btn-small" onclick="sendReminderEmail('${p.email}')">
                            알림 발송
                        </button>
                    </td>
                </tr>
            `).join('')
        : '<tr><td colspan="5" style="text-align:center;">모두 가입 완료!</td></tr>';
    
    document.getElementById('pending-prov-list').innerHTML = html;
}
```

## 6. 흐름도

```
111명 연락처 (CSV)
       ↓
[관리자] admin.html에서 CSV 업로드
       ↓
DB: provisional_members 테이블에 저장
(이름, 이메일, 출처 3개 필드만)
       ↓
📧 예비 멤버들에게 알림
(카톡, 페이스북, 이메일 등으로 수동 통지)
"join.html에 와서 가입을 완료하세요"
       ↓
예비 멤버가 join.html 방문
       ↓
"이메일 입력" → DB에서 확인
       ↓
정보 입력 (전화, 소개, 관심사, 비밀번호)
       ↓
Supabase 계정 생성 (password 포함)
+ profiles 테이블에 정보 저장
       ↓
✅ 정식 회원으로 전환 완료
(auth.users + profiles)
```

## 7. 핵심 특징

| 특징 | 설명 |
|------|------|
| **비밀번호 없음** | 예비 멤버 등록 시 비밀번호 설정 불필요 |
| **이메일 확인** | 자신의 이메일로만 가입 완료 가능 |
| **중복 방지** | 기존 회원 이메일 자동 필터링 |
| **간단한 등록** | 이름 + 이메일 2개 필드만 DB에 저장 |
| **정보 입력 자유** | 전화, 소개, 관심사는 선택사항 (비밀번호만 필수) |
| **진행 상황 추적** | 관리자가 제출 현황 실시간 조회 |

## 9. 주의사항

✅ **하면 안 되는 것:**
- 예비 멤버를 "회원"이라고 부르기
- 비밀번호 생성 + 발송
- 예비 멤버 자동 이메일 발송 (알림은 수동)

✅ **해야 하는 것:**
- 중복 이메일 필터링
- 정보 입력 후 진짜 회원이 되기
- 예비 멤버 제출 상황 추적
